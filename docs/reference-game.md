# Reference game: Harbor Market

An original, small card game used to prove the rules runtime, hidden information, the 2D table and the protocol end to end. It lives in `games/harbor-market` and is built with the public SDK only. Keep it simple; it is a test fixture, not a product.

It exercises: seeded shuffle, hidden hands, a public market, a die roll at turn start, two phases, turn order, end-of-round completion, scoring with tie-breaks, `legalMoves`, `present`, `interpret` and `actions`.

## Components

| Component   | Count                                                                            | Declaration                                                                |
| ----------- | -------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| Goods cards | 45: five goods (fish, salt, silk, spice, tea) × values 1, 1, 1, 1, 2, 2, 2, 3, 3 | 15 `card` defs `<good>-<value>`, 63 × 88 mm, back `goods-back`             |
| Card back   | 1                                                                                | `cardBack` def `goods-back`                                                |
| Tide die    | 1                                                                                | `die` def `tide`, 6 sides, 16 mm, faces Fish, Salt, Silk, Spice, Tea, Calm |

Card art for the fixture can be generated by `@bgp/card-generator` from a template and a 15-row CSV (good, value, color).

## Setup

Players: 2–4. Option `shortGame` (boolean, default false).

1. Create 45 card instances, each with an ID from `random.id()`; shuffle them into the deck.
2. If `shortGame`, move the top 15 deck cards out of the game (`boxed`, never shown).
3. Deal 4 cards to each seat's hand, in seat order, one at a time.
4. Fill the market with 4 cards from the deck, face up.
5. Seat `"0"` starts. At the start of every turn (`turn.onBegin`), roll the tide die: faces 1–5 set the tide to that good, 6 sets it to `calm`.

## A turn

Phase `main`: the current seat takes **exactly one** action.

| Move      | Args                       | Effect                                                                                                                                                                                                                                  | Rejected when (`gameCode`)                                                                          |
| --------- | -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| `swap`    | `{ hand: id, market: id }` | Exchange one hand card with one market card                                                                                                                                                                                             | Card not in your hand (`NOT_IN_HAND`) or not in the market (`NOT_IN_MARKET`)                        |
| `ship`    | `{ cards: id[] }`          | Move 2+ hand cards of **one good** to your harbor, face up. Score the sum of their values, plus 2 per card if their good matches the tide. Then the leftmost market card goes to the discard pile and the market refills from the deck. | Fewer than 2 cards (`TOO_FEW_CARDS`), mixed goods (`MIXED_GOODS`), card not in hand (`NOT_IN_HAND`) |
| `restock` | —                          | Draw 2 cards from the deck (1 if only 1 is left)                                                                                                                                                                                        | Deck empty (`DECK_EMPTY`)                                                                           |
| `pass`    | —                          | Do nothing                                                                                                                                                                                                                              | Any other move is legal (`PASS_NOT_ALLOWED`)                                                        |

After the action:

- If your hand has more than 6 cards, enter phase `discard`. Move `discard { cards: id[] }` must name exactly `hand − 6` of your hand cards (`WRONG_DISCARD_COUNT`); they go face up to the discard pile. Then return to phase `main`.
- Otherwise, or after discarding, the turn ends.

## End of the game

- The end is **triggered** the moment the deck becomes empty (by a restock or a market refill). The market may then have fewer than 4 cards.
- Play continues until the last seat in order has finished its turn, so everyone has had the same number of turns. Then the game ends with `events.endGame(result)`.
- The winner has the highest score. Tie: more cards in harbor. Still tied: shared win (several winners).

## State (authoritative)

```ts
type Good = "fish" | "salt" | "silk" | "spice" | "tea";

interface HarborState {
  cards: Record<string, { good: Good; value: 1 | 2 | 3 }>; // identity by instance id
  deck: string[]; // top = last element
  boxed: string[];
  market: string[]; // left to right
  discard: string[]; // top = last element
  hands: Record<SeatId, string[]>;
  harbors: Record<SeatId, string[]>;
  scores: Record<SeatId, number>;
  tide: Good | "calm" | null;
  tideFace: number | null; // 1..6
  endTriggered: boolean;
}
```

## View (what one seat may know)

```ts
interface Card {
  id: string;
  good: Good;
  value: number;
}

interface HarborView {
  hand: Card[]; // own hand; [] for spectators
  handCounts: Record<SeatId, number>; // everyone
  deckCount: number;
  market: Card[];
  discard: Card[]; // public, face up
  harbors: Record<SeatId, Card[]>;
  scores: Record<SeatId, number>;
  tide: Good | "calm" | null;
  tideFace: number | null;
  endTriggered: boolean;
}
```

The view must not contain: other seats' hand card IDs or identities, deck order or identities, boxed cards, or `cards` entries for anything hidden from this seat.

## Table layout (`present`)

Table 900 × 900 mm, origin at the center, seat `"0"` at the bottom (negative `y`). Positions may be tuned; keep the arrangement.

| Zone            | Layout | Center (x, y) mm              | Size (w × h) mm |
| --------------- | ------ | ----------------------------- | --------------- |
| `deck`          | stack  | (−230, 0)                     | 80 × 110        |
| `tide`          | stack  | (−230, 120)                   | 40 × 40         |
| `market`        | row    | (20, 0)                       | 300 × 110       |
| `discard`       | stack  | (260, 0)                      | 80 × 110        |
| `hand:<seat>`   | fan    | seat edge, 380 mm from center | 500 × 110       |
| `harbor:<seat>` | row    | seat edge, 250 mm from center | 600 × 110       |

Seat edges: 2 players use bottom (`"0"`) and top (`"1"`); 3–4 players go clockwise bottom, left, top, right, with side seats' zones rotated 90°.

Presentation rules:

- Own hand: face up with `def`, selectable and draggable in your turn.
- Other hands: one face-down item per card with IDs `x:<seat>:<index>`, no `def`, back `goods-back`.
- Deck: one face-down item `deck-top` with `badge` = deck count, when the deck is not empty.
- Market, discard top, harbors: face up with `def`.
- Tide die: one item with `value` = `tideFace`.
- HUD: scores, hand counts, active seat. Prompt: "Your turn: swap, ship or restock", "Discard N cards", or "Waiting for <name>".

## Input

- `interpret`: dropping one of your hand cards on the market zone at `index` → `swap { hand, market: market[index] }`. Other gestures → `null`.
- `actions(view, info, selection)`:
  - **Ship selected** — enabled when the selection is 2+ of your hand cards of one good.
  - **Restock** — enabled when the deck is not empty.
  - **Pass** — enabled only when no other move is legal.
  - In phase `discard`: **Discard selected** — enabled when exactly `hand − 6` cards are selected.

## `legalMoves`

- `main`: every hand × market `swap`; every subset of 2+ same-good hand cards for `ship`; `restock` if the deck is not empty; `pass` only if nothing else is legal.
- `discard`: every combination of exactly `hand − 6` hand cards.

## Required tests

| Test               | Check                                                                                                                           |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| Setup              | 45 (or 30) cards accounted for; 4 per hand; market of 4; tide rolled for seat `"0"`                                             |
| Scoring            | Shipping fish 1+2+3 with tide fish scores 6 + 6 = 12; with another tide scores 6                                                |
| Market refill      | After a ship, the leftmost market card is in the discard pile and the market refilled from the deck                             |
| Hand limit         | Restock to 8 cards enters `discard`; discarding the wrong count is rejected with `WRONG_DISCARD_COUNT`                          |
| End of round       | Deck empties during seat `"1"` of 4: seats `"2"` and `"3"` still play; the game ends after `"3"`                                |
| Tie-breaks         | Equal scores: more harbor cards wins; still equal: both win                                                                     |
| Illegal moves      | Each `gameCode` in the move table is produced by a crafted intent                                                               |
| Hidden information | For every seat and every step of 200 random games, the seat's view contains none of the IDs in other hands, the deck or the box |
| Determinism        | 1,000 random games via `legalMoves`: replaying each from seed and events gives the same state hash                              |
